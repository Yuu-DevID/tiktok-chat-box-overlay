Adding a source in OBS
1In OBS press + under Sources and choose Browser.
2Paste the copied URL and set Width/Height to the size noted under each page.
3Tick Shutdown source when not visible and Refresh browser when scene becomes active.
4Come back to the Overlays tab to preview each one while you're live.
Notes
iChat / Pinned / Top Donate / Timer / Summary all work as Browser Sources via their copy buttons.
iChat window is a normal desktop window, not an OBS widget — open it with the button in the header and pin it on top with your desktop environment.
iMusic is the real audio source — in OBS do not tick Shutdown source when not visible, or songs stop when you switch scenes.
iSong requests need YOUTUBE_API_KEY in .env. No key = feature off. Viewers request with m!p <song name> or m!p <YouTube link>.
iWith Auto on, a valid request starts playing right away; turn it off to approve each one from the Panel.
iSession totals (Comments/Gifts/Diamonds) are shown on demand from the left sidebar — nothing updates automatically.
iRust overlay binary: jalankan ./tiktok-chat-overlay-linux/run-overlay.sh (atau set CHATBOX_URL). Butuh WebKitGTK 4.1 (mis. webkit2gtk-4.1 di Arch/CachyOS).
